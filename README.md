A curated collection of competitive programming solutions from [Codeforces](https://codeforces.com/). This repository serves as an archive of various problems solved during practice sessions, focusing on clean, readable, and efficient implementations.

## 📂 Repository Structure

The project is organized by programming language:

- **[CPP/](./CPP)**: High-performance solutions implemented in C++.
- **[JavaScript/](./JavaScript)**: Modern JavaScript (Node.js) implementations focusing on readability and algorithm clarity.
- **[Python/](./Python)**: Concise and readable Python solutions.

## 🚀 Getting Started

### Prerequisites

- For C++: A modern compiler like `g++` (supporting C++17 or later).
- For JavaScript: [Node.js](https://nodejs.org/) installed on your system.
- For Python: [Python 3.x](https://www.python.org/) installed on your system.

## 🏃 Running Solutions

#### C++
To compile and run a C++ solution:
```bash
g++ -O3 CPP/<problem_id>.cpp -o solution
./solution < input.txt
```

#### JavaScript
To run a JavaScript solution using Node.js:
```bash
node JavaScript/<problem_id>.js < input.txt
```

#### Python
To run a Python solution:
```bash
python Python/<problem_id>.py < input.txt
```
